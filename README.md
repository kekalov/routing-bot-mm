# AnalytiQA — шаблон для аналитического роутинга в корпоративном мессенджере

Коротко: это каркас решения, которое читает сообщения в корпоративном мессенджере и возвращает структурированную подсказку — тему (Topic), ответственного (Analyst), канал (Channel) и причину (Reason). В репозитории нет секретов и приватной логики — всё важное подставляете сами.

## Зачем
- Снять ручную маршрутизацию вопросов
- Ускорить первые ответы и прозрачность процессов
- Дать простой способ развернуть похожее у себя

## Как запустить (5 шагов)
1) Склонируйте проект
```bash
git clone https://github.com/kekalov/analytiqa-template.git
cd analytiqa-template
```
2) Подготовьте окружение
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```
3) Настройте переменные окружения
- Скопируйте `.env.template` → `.env`
- Заполните ключи вашего LLM провайдера (см. примеры в `src/bot.py` и комментарии в `.env.template`)
- Укажите токены корпоративного мессенджера (бот-токен, app-токен, id канала) — поля уже в `.env.template`

4) Опишите логику классификации
- Откройте `evaluation/prompt.txt`
- Впишите категории, владельцев, каналы и требование вернуть только JSON
- Фолбэк-парсер подстрахует, если модель вернёт не-JSON

5) Запустите демо-бота
```bash
./start_bot.sh
```
Дальше отправьте тестовое упоминание бота в корпоративном мессенджере — он ответит в треде блоком «Classification Result».

## Что настроить под себя
- `evaluation/prompt.txt` — ваша матрица владения (темы → ответственные → каналы → ключевые слова → метрики)
- `.env` — ключи LLM и токены вашего корпоративного мессенджера
- `src/bot.py` — минимальный демо-бот (адаптируйте под ваш мессенджер: Telegram, VK Teams, и др.)
- `requirements.txt` — замените библиотеку мессенджера на библиотеку вашего провайдера

## Безопасность
- Реальные ключи — только в `.env` (он в `.gitignore`)
- Минимально необходимые права для бота
- См. `SECURITY.md` для краткого чек-листа

## Как это работает (в двух словах)
- Событие из корпоративного мессенджера → демо-бот (`src/bot.py`) → ваш LLM провайдер →
- Ждём строго JSON; если модель прислала текст, включается фолбэк-парсер →
- Отправляем ответ в тред: Topic / Analyst / Channel / Reason

Готово. Этот шаблон — «скелет»: вставьте свой промпт, ключи и категории — и получите рабочий прототип в пару часов.
